Bundled sample games
====================

Every file in this folder is copied into the library on first launch by
SampleGameInstaller. The display title comes from the file name, so name files
the way they should appear in the app.

A cover image with the SAME base name in ../sample_covers/ (jpg/png/webp) is
used as the game's thumbnail.

All games are homebrew released under licenses that allow commercial
redistribution. Attribution is shown in Settings > Open source licenses
(SampleGames.ALL). Keep that list in sync when adding or removing a game.

- Tobu Tobu Girl.gb              Tangram Games      MIT (code), CC BY 4.0 (assets)
- uCity.gbc                      Antonio Nino Diaz  GPL-3.0+ (code), CC BY-SA 4.0 (media)
- Libbet and the Magic Floor.gb  Damian Yerrick     zlib
- Concentration Room.nes         Damian Yerrick     GPL-3.0+ (ROM redistribution exception)
- Attack on Voxelburg.gba        John Tsiombikas    GPL-3.0+
